Lexicon

Personal project · 2026 · Personal knowledge engine

Save everything you read. Search it by meaning. Get answers that cite their sources.

A browser extension captures pages as you read; a Next.js app indexes them and answers questions across everything you’ve saved.

90%top-1 retrieval relevance across tested queries
Next.jsSupabasepgvectorGemini APITailwindChrome MV3
Code
  • Manifest V3 extension that captures and sends page content on demand.
  • Hybrid search on Supabase fusing Postgres full-text and pgvector similarity with Reciprocal Rank Fusion.
  • Answers carry inline footnote citations that link back to the saved page, so Lexicon is a full-stack RAG platform you can check.
  • My own design system, “The Athenaeum”: six colour tokens, two typefaces, designed loading, empty and error states.
how does hybrid search rank results?

Keyword and vector results are ranked separately, then merged with Reciprocal Rank Fusion1, so a page that does well in both rises to the top2.
